# 广告素材审核工作台

面向广告投放前审核的批量处理系统。工作台将素材接入、AI 初筛、证据核对和人工决策放在同一条流程中，帮助审核人员按客户、活动和渠道处理待投放文案与图片。AI 结果用于提示风险和补充资料需求；最终投放决定由审核人员记录。

[在线工作台](https://ad-review-assistant.onrender.com/)

## 主要功能

- **统一接入**：通过 Excel 批量导入或手动提交文案、图片和 PDF；两种入口进入同一审核队列。上游系统也可通过批次 API 提交文字素材。
- **批次处理**：后台执行审核任务，支持进度查询、失败重试和同批次相同图片组合的识别结果复用。
- **图文审核**：视觉模型逐页转录可见文字，并直接查看原图判断画面表达和信息呈现；审核模型结合文案、识别文字及补充资料逐项检查规则。
- **证据化报告**：按规则输出问题原文、判断依据、风险等级、修改建议及待补充证据。引用无法定位时标记为待核对。
- **人工复核**：审核人员在同一页面对照原文件与机器结果，记录通过、退回修改或待补证；处理记录保留在批次中。

## 审核流程

1. **提交素材**：按客户、活动和投放渠道创建批次。单批最多 100 条素材。
2. **识别内容**：图片和 PDF 逐页转为模型可处理的图像，提取文字、清晰度问题和与审核相关的版面观察。
3. **逐项审核**：有图任务将原图、文案、转录结果和补充资料一并交给视觉模型；纯文字任务由配置的审核模型处理。模型依据 [规则库](rules.json) 和 [审核提示词](audit_prompt.md) 输出结构化检查结果。
4. **程序校验**：验证规则编号、状态、引用和输出结构，并执行必要的强制校验。识别或引用不确定的内容交由人工核对。
5. **人工决策**：审核人员查看原始素材、逐条依据与处理历史，保存最终处理结论。

系统将“未发现明显风险”与“人工通过”分开记录，不以机器初筛结果自动放行素材。

## 工作台与接口

首页 `/` 为审核工作台，`/batches` 为兼容地址。工作台提供跨批次队列、风险与处理状态筛选、原文件预览、审核详情和人工结论记录。

| 接口 | 用途 |
| --- | --- |
| `POST /api/batches/excel` | 导入 Excel 素材批次 |
| `POST /api/batches/manual` | 手动提交图文素材 |
| `POST /api/batches` | 从上游系统提交文字批次 |
| `GET /api/batches/<batch_id>` | 查询批次进度 |
| `GET /api/batches/<batch_id>/items/<job_id>` | 查询单条素材和审核报告 |
| `GET /api/status` | 查看服务及模型配置状态 |

批次接口和数据结构见 [接口与架构说明](BATCH_MVP.md)。

## 运行环境

- Python 3.12
- 模型服务 API Key，以及具备图片输入能力的视觉模型
- SQLite（默认批次存储）

在项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

浏览器访问 `http://127.0.0.1:8765`。模型配置可参考 [config.example.json](config.example.json)。本地可使用不提交到仓库的 `config.json`；部署环境建议使用环境变量：

| 环境变量 | 作用 |
| --- | --- |
| `DASHSCOPE_API_KEY` | 模型服务密钥；`AD_REVIEW_API_KEY` 可覆盖它 |
| `DASHSCOPE_BASE_URL` | 模型服务接口地址 |
| `QWEN_MODEL` | 纯文字任务使用的审核模型 |
| `QWEN_VISION_MODEL` | 图片识别及原图审核使用的模型 |
| `APP_ACCESS_CODE` | 公网工作台访问码，至少 12 位 |

示例配置和 [render.yaml](render.yaml) 均将审核模型与视觉模型设为 `qwen-vl-plus`。实际调用以运行环境中的配置为准。API Key 应只保存在本地配置或部署平台的环境变量中。

## 素材与数据

支持纯文字、静态 PNG/JPG/WEBP 图片和 PDF。手动提交每条素材最多 4 个文件，合计不超过 8 MB、4 页；单张图片上限 2400 万像素。Excel 文件上限 20 MB。超限的 PDF 会整份拒绝，不截取部分页面继续审核。

批次、原文件、报告和人工处理记录暂存在服务端 SQLite 中，默认 24 小时后清理。当前实现面向单实例运行；未配置持久磁盘时，服务重启或重新部署可能丢失未清理批次。共享访问码和手填审核人名称不提供用户身份认证或客户数据隔离。

## 规则与质量验证

当前规则库包含 A-01～A-10 十条通用初筛规则，覆盖部分常见宣传风险。规则扩展方向见 [规则体系规划](RULES_PLAN.md)。行业、客户和投放渠道的专属要求尚未纳入；补充资料目前以文字形式提交，系统不独立核验外部证明的真实性。

运行自动化测试：

```powershell
.\.venv\Scripts\python.exe -m unittest
```

测试覆盖规则校验、图文输入、PDF 多页处理、批次队列、访问控制和人工处理记录。模型调用在自动化测试中使用模拟响应，不代表线上审核准确率。[评测样例](evaluation_cases.json) 可用于边界案例检查；`python evaluate.py --live` 会调用真实模型并产生费用。评测方法与现有结果见 [验证说明](VALIDATION.md)。
