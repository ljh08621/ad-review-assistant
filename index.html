01 / 提交宣传文案

支持文字、TXT、PNG / JPG / WEBP 和 PDF。图片与 PDF 先识别、核对，再审核。单文件最多 8 MB，PDF 最多 4 页。

规则模式不调用审核模型；上传识别仍需视觉模型。不核验补充资料。

文件将上传到应用服务器，并发送至配置的百炼视觉模型。程序不保存原文件。

使用说明与能力边界

1. 输入文案并确认材料完整性。
2. 选择本地或 AI 模式并开始审核。
3. 根据问题补充证据或修改，再次审核。
4. 敏感词必须人工复核。本版本所有结果均建议人工确认，不自动放行。
报告仅保留在当前页面；刷新会清空。可以导出 JSON 或打印保存 PDF。

02 / 审核报告

等待提交材料点击“加载风险样例”，即可开始第一次测试。

每条问题包含原文、规则、等级、建议和人工审核要求。

来源：题目给定规则 · 版本 exam-v1.0 · 提示词 audit-v2.1。高／中等级是本项目的分流配置，不代表法律结论。规则存放在独立的 rules.json 中。
